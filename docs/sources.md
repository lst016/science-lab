# 教材与参考来源

## 教学内容

使用本项目父目录中已采集的五本人教版六三制教材：物理八上（来源编号0486）、八下（0487）、九年级全册（0485），化学九上（0181）、九下（0186）。源PDF共170、131、218、199、127页。原始下载清单位于父目录 logs/补充版本采集清单.json，包含来源页、实际下载地址与SHA-256。

这些文件由公开教材镜像获取，不等同于已核实的2026学年各地现行印次。网站的revision标签不能直接作为版权页出版年。原始PDF不复制进这个Git项目；实验内容用原创概括，保留PDF来源页用于核对。

## 视觉概念

本项目 docs/references/ 下两张图为本次生成的界面方向图。实际界面文字、控件、书籍和实验均为代码实现；概念不代表每项实验已实现或科学模型已验证。

## 模拟边界

数据项包含模型描述、公式和适用限制；定量近似、定性演示及微观示意应分别说明。界面操作产生的是教学模型输出，不是实际实验测量记录；化学变化不做精确反应动力学，粒子图像不是真实尺寸和轨迹。
