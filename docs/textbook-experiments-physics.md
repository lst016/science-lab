# 人教版初中物理实验与动手活动盘点

## 来源与覆盖口径

本盘点对应仓库 `books.ts` 中三册人教版物理教材：八年级上册（来源编号 0486，PDF 170 页）、八年级下册（0487，PDF 131 页）和九年级全一册（0485，PDF 218 页）。逐条核对 `../tmp/textbook-source/0486.txt`、`0487.txt`、`0485.txt` 中对应的 `=== PDF PAGE n ===` 页段；候选标记索引用于定位，不单独作为纳入依据。`pdfPage` 使用 PDF 页码，未从页脚推算 `printedPage`。

纳入教材明确提出的实验、演示、探究，以及有具体材料或操作要求的“想想做做”、跨学科实践/制作活动。纯思考题、练习题中的假设题、仅介绍原理的段落不计作动手活动。每项用原创文字概括器材、操作和结论；模型参数用于可视化比较，不能当成教材实测值。涉及高温、激光、短路、腐蚀性物质等情境时，条目标明虚拟演示或安全限制。

## 8-1 八年级上册（0486）

原有标记实验、演示和探究条目保留。另加入明确的动手活动：双放大镜、漏斗托乒乓球、橡皮筋振动发声、桌面传声、钢尺振动与音调、隔音房间模型、自制液体温度计、酒精蒸发致冷、厨房物态变化项目、阳光测焦距、小孔成像、水和镜面色散、模型照相机、望远镜制作。相同页中不同操作或研究变量各自建模，未将所有活动并成一个通用场景。

条目所对应的 PDF 页码均见数据项；例如，隔音房间模型为第 60 页，自制温度计第 66 页，纸锅活动第 73 页，厨房物态变化项目第 82 页，小孔成像第 97 页，望远镜实践第 137 页。纸锅活动由第 73 页的“想想做做”明确要求实际制作并加热；虚拟模型不鼓励家庭使用明火复现。

## 8-2 八年级下册（0487）

原有标记实验、演示和探究条目保留。另加入门上不同位置施力、磁体小车/推墙反冲、简易气压计、鸡蛋浮沉、橡皮泥船、微型密度计、活塞式抽水机和两纸片间吹气活动。跨学科制作条目包括活塞式抽水机（第 61 页）、微型密度计（第 82 页）和杆秤（第 116 页）；鸡蛋浮沉与橡皮泥船取自第 79 页的动手活动。

## 限制

本清单是供交互模型制作使用的活动盘点，不是教材逐字目录，也不声称覆盖所有练习、家庭观察或可自行设计的探究方案。每项的 `sourceVerified` 只表示已核对来源页存在相应活动内容，不表示模型参数已经实验校准。实际化学/物理测量结果、材料规格和安全条件需以教师指导及具体器材为准。
