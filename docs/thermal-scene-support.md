# 热学与粒子 3D 场景支持

新增 `ThermalRig` 覆盖 physics 书籍的热学（heat）和粒子（particle）器材场景。画面使用共享 kit 玻璃、金属、液体材质，并从 rig IO 读取实验参数、模型状态和实验时间；动画不写 React state，因此暂停时冻结，重置后回到模型初始状态。

| 场景 | 主要可见变化 |
|---|---|
| 冷水复沸 | 倒置圆底烧瓶、冷水托盘；模型沸腾状态驱动气泡 |
| 简易温度计 | 有色液体、细管液柱；浴温和细管直径影响液柱高度 |
| 测水温、熔化、沸腾 | 水浴/烧杯、温度计刻度；读数、熔化比例、沸点与气泡读取模型状态 |
| 酒精蒸发致冷 | 温度计玻璃泡酒精棉球与扇叶；气流强度驱动扇叶 |
| 厨房物态变化 | 蒸发、沸腾、冷却/凝结器皿；主题和温度读数接入模型 |
| 比热容比较 | 等质量水/油双杯和各自温度计，按相同功率、时间展示不同温升 |
| 压缩空气、蒸汽做功 | 玻璃筒活塞或试管松置塞；压缩量、加热/水量驱动活塞位置 |
| 焦耳热 | 低压电源、电阻丝和 U 形液柱示意；按 I²Rt 的比较关系显示液柱差，不使用火焰热源 |
| 气体扩散 | 上下玻璃集气瓶、不同颜色分子；经过时间与温度改变混合范围和运动活跃度 |
| 墨水扩散 | 冷热水双杯和墨滴粒子；温差/时间驱动扩散范围 |
| 铅柱引力 | 接触铅柱、吊钩与砝码；接触程度改变接合间隙，载荷改变砝码比例 |

这些场景是课堂定性示意。粒子运动、熔化进度、热传递、液柱与活塞行程均采用视觉比例；没有拟合实际传热、扩散、沸腾气泡动力学或仪器校准。比热容比较用模型给出的功率、时间、质量和水/油比热容估算温升。焦耳热液柱突出比较方向，不模拟密闭气体的真实压强标定。
