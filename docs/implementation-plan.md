# 理化实验书 Implementation Plan

Goal: 创建可本地运行的五册人教版初中理化互动3D动态书书库。
Architecture: Vite+React+TypeScript，Three.js/R3F承载程序化场景；HTML保持书内正文和控制可读；内容数据和场景族分离。

1. 内容worker：从五册PDF盘点实验、记录页码，输出src/data类型和完整数据，做覆盖审计。
2. Claude：依据两张概念和参考页面实现书库、阅读器、书页动画、场景族、参数计算与控制；不改src/data。
3. 主代理：协调接口、提供源信息、修复集成问题、准备来源与使用说明。
4. MiniMax：执行明确的typecheck/build和程序化数据/核心交互验证，整理实际命令与退出码。
5. 主代理：IAB桌面/移动视图检查，验证全部5册导航、代表实验操作与恢复；检查概念与实现差异，修复可改问题。
6. 完成：记录限制及覆盖，不把教学示意宣称精确仿真；创建本地初始Git提交，运行预览并交付入口。不发布远程仓库、不部署。
