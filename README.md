# 理化实验室

从书库选一本教材，翻开立体书，调整参数、触发实验操作，观察装置与读数变化。

本地项目，Vite + React + TypeScript + Three.js。界面、器材几何和实验文字为本项目实现。源码保存在 [GitHub：lst016/science-lab](https://github.com/lst016/science-lab)，尚未部署在线站点。

## 启动

需要 Node.js 22.12+。首次运行：

```sh
npm ci
npm run dev
```

打开 http://127.0.0.1:5180/ 。正式打包用 `npm run build`，预览打包结果用 `npm run preview`。

## 五册内容

| 教材 | 活动数 |
|---|---:|
| 物理八年级上册 | 40 |
| 物理八年级下册 | 27 |
| 物理九年级全一册 | 34 |
| 化学九年级上册 | 46 |
| 化学九年级下册 | 34 |
| 合计 | 181 |

依据已采集的五册人教版教材，收录明确的实验、演示、探究和动手实践。同一实验的不同研究变量可能拆成多个活动，因此活动数不等同于教材的编号实验数。纯思考题、资料调查和练习不在覆盖范围。内容依据与页码核对方法见 [物理盘点](docs/textbook-experiments-physics.md)、[化学盘点](docs/textbook-experiments-chemistry.md)、[来源说明](docs/sources.md)。

每项含操作步骤、器材、目的、结论、PDF来源页和模型限制。原始教材保存在父目录的“教材PDF”，未纳入本Git项目；网页标注页码，核对原书请打开对应PDF。镜像来源的版本标签不代表已核实为2026学年现行印次。

## 操作

- 书库点击封面；每册自动记住上次打开的活动。
- 底栏可返回书库、打开可搜索目录、前后翻页、暂停和重置。
- 实验左页有“步骤与操作”“器材与结论”“模型说明”三个标签；长内容可在页内滚动。
- 方向键翻页，空格暂停/播放，L打开目录，Esc关闭目录或返回全景；编辑参数时不抢占方向键。
- 底栏“近看”可平滑放大实验装置，再点“全景”回到整本书；翻页自动恢复全景。
- 地址中的 `#/book/书籍ID/实验ID` 可刷新并定位实验。
- 手机竖屏采用上方单页3D、下方可滚动说明；横屏时实验与说明并排。工具栏与参数适配触控，并留出屏幕安全区域。WebGL不可用时显示可操作的文字与读数。

## 模型边界

181项表示教材活动内容覆盖，不表示181个经过实物校准的精确仿真。器材按场景族和实验变体复用程序化几何。

反射、透镜、欧姆定律、密度、压强、浮力、杠杆等使用教学公式及相应单位。化学反应、扩散、燃烧、微观粒子和长期实践以定性现象或过程示意呈现；不提供真实反应速率、真实粒子轨迹或种植观测数据。画面中的运动速度、色彩、几何尺寸与粒子数量可能为便于观察而夸张，各项“模型说明”为准。虚拟操作不能替代教师指导的实物实验。

## 检查

```sh
npm run typecheck
npm test
npm run build
npm run audit:parameters
npm run test:camera
```

`npm test` 检查五册数据完整性、来源页范围、关键科学规律、全部活动的默认/最小/最大参数输入，以及7种舞台尺寸的全景/近景取景边界。参数审计报告哪些参数不改变纯模型输出；这类参数可能只控制画面，需结合场景核对。自动检查不证明每个3D装置的所有细节均已逐项人工验收。
